日付の読み方

「開始日」は、発表日・ベータ公開日・正式公開日のどれを取るかで変わる。この表は、断りのない限りベータ版の公開日か、サービスを始めた日で揃えた。資料によって日付が違うときは、Google の発表を優先した。

根拠の列: 「公式」は Google の公式ブログ・プレスリリースで確かめたもの。「他資料」は Google の公式な記載が見つからず、Wikipedia や IT ニュース記事によったもの。
